# TEST-CODE

A shared, open-source academic content repository for the **English Literature Library** and the **English Literature Library Experiment**.

The websites consume this repository as a common source of truth. The repository is content-first: website code stays in the library projects.

## Catalogues

- English Literature
- History
- Political Science
- Economics
- Accountancy
- Physics
- Chemistry
- Biology
- Mathematics
- Computer Science
- Programming
- AI/ML

## Rights and provenance

Every work should record its original source, edition, license, jurisdiction, attribution requirements, and redistribution status. A free-book catalogue or external link does not by itself grant permission to copy the linked work.

TEST-CODE may host full text only when the recorded rights permit redistribution. Otherwise it can hold metadata and a legitimate external source link.

## Programming pilot

The Programming catalogue is the first multi-source pilot. It starts with a curated set of high-quality programming resources and records their official source pages. These entries are initially **external-source records**, not copied ebook files, until their edition-specific redistribution rights are verified.
