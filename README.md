# English Literature Book Repository

A shared content repository for the **English Literature Library** and the **English Literature Library Experiment**.

This repository stores structured literary works, authors, periods, themes, characters, chapters, and educational metadata. The websites consume this repository as a common source of truth.

## Scope

- English literature and related educational texts
- Works studied in the English Literature curriculum
- Authors and literary periods
- Chapter/section metadata
- Themes, characters, genres, and study notes

## Structure

```
books/
authors/
periods/
collections/
schema/
```

The repository is intentionally content-first. Website code belongs in the library projects, not here.
