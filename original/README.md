# Original Writing

Original educational and editorial material created for the English Literature Library.

This area is separate from primary literary texts. It can contain:
- original literary analysis
- chapter and work summaries
- study guides
- lecture-style notes
- contextual essays
- reading guides
- glossaries
- comparative literature notes
- original questions and revision material

All material in this directory should be clearly marked as original library content and should not imitate or reproduce copyrighted source text.
